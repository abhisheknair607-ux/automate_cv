# Garamaal — Electric Entrance
Standalone interactive HTML landing page, following the uploaded GCORE circuit-energy video as the visual and motion reference.

## Experience
- Home: copper energy pulses travel from six circuit endpoints to a central Garamaal core.
- Scroll-controlled continuous electrical current flows down into Discover Jobs → Apply → Network → Statistics.
- Arriving at each section powers up its main CTA with a copper glow.
- Clickable core terminal shortcuts, chapter links, and separate prototype detail views.
- Royal Espresso (default) and Royal Porcelain, using the approved exact hex palette.
- A fully functioning webpage: no video, no external assets, no backend calls; keyboard/reduced-motion support.

## Routes
In the standalone HTML, click a section to open its detail view (`#/discover`, `#/apply`, `#/network`, `#/statistics`). The detail view links into existing Garamaal paths:
- Discover, Apply, Statistics → https://garamaal.web.app/prototype
- Network → https://garamaal.web.app/social

## QA and deployment safety
Local Chromium checks passed at 320, 390, 768 and 1440px for main button glow, navigation, return, theme switch, JavaScript exceptions, and horizontal overflow. This is **not deployed**. Existing Jobs/Social/CV app files have not been changed. Keep under a separate preview URL for stakeholder sign-off before integration.
