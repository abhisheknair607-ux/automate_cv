# Pooja automation evidence handoff

The supplied Summary Doc is the evidence router. Select only evidence IDs
actually present there. Do not invent IDs, experience or qualifications.
Preserve the full analysis for audit. End with a standalone `STAGE2_HANDOFF`
heading and YAML using the existing workflow's fields: company, role_title,
cv_structure (`High Experience` or `Lower Experience`),
selected_professional_evidence, selected_projects,
selected_achievements_qualifications_skills, gaps, do_not_claim, and
stage3_evidence_to_retrieve_or_verify. Every selected evidence item must use
its exact `PR-`, `PROJ-`, `QUAL-`, `EDU-`, `SKILL-`, or `ACH-` ID from the router.
